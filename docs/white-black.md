A Z.PAY tem **dois perfis** de conta. Mesmo painel e mesma API; taxas e limites mudam.

## White

Para operação convencional (bots, mediação, SaaS, comunidades).

| Item | Valor |
| --- | --- |
| Cash-in | **R$ 0,50** |
| Acima de R$ 1.000 | 1% + R$ 0,50 |
| Cashout API | R$ 0,50 |
| Ticket máx. cash-in | R$ 2.000 |
| Cashout até | R$ 10.000 (com KYC) |

## Black

Estrutura separada para alto risco (adulto, hot, etc.).

| Item | Valor |
| --- | --- |
| Cash-in | **6% + R$ 1,50** |
| Cashout API | R$ 1,50 |
| Ticket máx. cash-in | R$ 500 |
| Cashout até | R$ 10.000 (com KYC) |
| Processamento | dedicado (gateway black) |

O tipo da conta define qual chave de gateway a API usa por baixo. Sem mensalidade nos dois.
